# Separate Bobbers Mod - v2.0.0

Мод для Minecraft Java 1.21.11 на Fabric, который создаёт уникальные поплавки для каждой удочки.

## Возможности ✨

✅ **Отдельный поплавок для каждой удочки** - если взять другую удочку, появится новый поплавок  
✅ **Сохранение поплавков** - поплавки остаются на месте после выхода из игры  
✅ **Беспроводной редстоун** - можно использовать поплавки как датчики (прижав их к нажимной плите)  
✅ **Автосохранение** - данные сохраняются каждые 5 минут и при остановке сервера  

## Установка

### Требования
- Minecraft 1.21.11
- Fabric Loader 0.16.9+
- Fabric API 0.107.0+

### Способ 1: Из релиза
1. Скачайте `separatebobbers-2.0.0.jar` из GitHub Releases
2. Поместите в папку `mods`

### Способ 2: Сборка из исходников
```bash
# Клонируем репозиторий
git clone https://github.com/nobben777-pixel/bobber.git
cd bobber

# Собираем мод
./gradlew build

# JAR файл будет в build/libs/
```

## Как это работает

### Система ID удочек
Каждой удочке автоматически присваивается уникальный ID и сохраняется в её NBT данные:
```
- RodId #1 (Удочка 1) → Поплавок #1
- RodId #2 (Удочка 2) → Поплавок #2
- RodId #3 (Удочка 3) → Поплавок #3
```

### Сохранение данных
Данные поплавков сохраняются в файл `separatebobbers_data.nbt` в папке мира:
```
world/
└── separatebobbers_data.nbt  ← Здесь хранятся все поплавки
```

При загрузке мира поплавки автоматически восстанавливаются.

## Использование в беспроводном редстоне

1. **Бросаем удочку** на нажимную плиту
2. **Поплавок** встанет на плиту и будет активировать её
3. **Уходим в Nether/другие измерения** - поплавок остаётся!
4. **При перезагрузке** поплавок восстанавливается в том же месте

## Файловая структура

```
src/main/java/com/example/separatebobbers/
├── SeparateBobbers.java           # Главный класс мода
├── BobberTracker.java             # Отслеживание поплавков
├── BobberPersistence.java         # Сохранение/загрузка
├── RodIds.java                    # Система ID удочек
└── mixin/
    ├── FishingRodItemMixin.java   # Перехват использования удочки
    └── FishingBobberEntityMixin.java  # Регистрация поплавков
```

## Технические детали

### Сохранение в NBT
```
{
  "Count": 2,
  "Bobber_0": {
    "BobberId": 100001,
    "PlayerId": 12345,
    "PlayerUUID": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
    "RodId": 100001,
    "X": 123.5,
    "Y": 64.0,
    "Z": 456.5,
    "Dimension": 0
  },
  "Bobber_1": { ... }
}
```

### События сервера
- `ServerStartedCallback` - загрузка поплавков при старте
- `ServerTickEvents.END_SERVER_TICK` - автосохранение каждые 5 минут
- `ServerStoppingCallback` - финальное сохранение при остановке
