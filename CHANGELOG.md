# Changelog - Separate Bobbers Mod

Все значимые изменения этого проекта будут задокументированы в этом файле.

## [2.0.0] - 2024-10-10

### ✨ Added (Добавлено)
- **BobberPersistence.java** - полная система сохранения/загрузки поплавков
- Автосохранение поплавков каждые 5 минут
- Восстановление поплавков при загрузке сервера
- Поддержка сохранения в разных измерениях (Overworld, Nether, End)
- NBT файл для персистентного хранения: `separatebobbers_data.nbt`
- Обработка событий сервера (SERVER_STARTED, SERVER_STOPPING)
- GitHub Actions для автоматической сборки при push
- GitHub Actions для автоматического создания релизов

### 🔧 Improved (Улучшено)
- Система отслеживания поплавков теперь потокобезопасна (ConcurrentHashMap)
- Лучшее логирование всех операций
- Подробная документация кода на русском языке
- Полная поддержка Fabric API 0.107.0+
- Обновлена версия Fabric Loader до 0.16.9

### 🐛 Fixed (Исправлено)
- Поплавки больше не исчезают при перезагрузке сервера
- Связь "удочка → поплавок" сохраняется между сессиями
- Правильная обработка удаления поплавков из памяти

### 📚 Documentation (Документация)
- Добавлены 4 подробных файла документации
- Диаграммы архитектуры и потоков событий
- Пошаговые инструкции по сборке
- Примеры использования беспроводного редстоуна

---

## [1.0.0] - 2024-10-09

### ✨ Added (Добавлено)
- Базовая функция отдельных поплавков для каждой удочки
- Система ID удочек (RodIds.java)
- Отслеживание поплавков (BobberTracker.java)
- Миксины для перехвата использования удочки
- Поддержка Minecraft 1.21.11
- Поддержка Fabric 0.16.9+

### 📦 Initial Release
- Первый релиз мода
- Каждой удочке свой уникальный поплавок
- Возможность бросать несколько удочек одновременно

## Версионирование

Этот проект использует [Semantic Versioning](https://semver.org/):

- **MAJOR** версия (X.0.0) - несовместимые изменения API
- **MINOR** версия (0.X.0) - новые функции, совместимые с предыдущей версией
- **PATCH** версия (0.0.X) - исправления ошибок

Примеры:
- 1.0.0 → 2.0.0 = MAJOR (добавлено сохранение)
- 2.0.0 → 2.1.0 = MINOR (новая фишка)
- 2.0.0 → 2.0.1 = PATCH (исправлен баг)
